\cvsection{Open Source}

\begin{cvparagraph}
\begin{itemize}[leftmargin=2ex, nosep, noitemsep, label=\textbullet]
  \item \textbf{conda and conda-forge}: Steering Council member for an ecosystem serving 1B+ package downloads a month ($\sim$27B to date). Led the governance overhaul of both projects, and an infrastructure audit and security hardening of the build farm CI (Azure Pipelines and GitHub Actions) against common supply chain attacks.
  \item \textbf{conda user experience and performance}: led and designed improvements to the conda CLI and to the mamba solver implementation for faster installs; currently working on deterministic environments and faster package verification.
  \item \textbf{JupyterLab and JupyterHub}: long-term contributor and maintainer. JupyterLab: 15K+ GitHub stars, 50M+ downloads a month; JupyterHub: 8.7K+ stars, widely deployed across universities and research institutions.
  \item \textbf{Nebari}: Steering Council member and former product owner of an open source platform for deploying reproducible AI and ML infrastructure.
  \item \textbf{Sphinx, PyData Sphinx Theme and Bokeh}: maintainer and contributor to documentation and visualisation tools used across the scientific Python stack.
  \item \textbf{Governance and stewardship}: Director and Fellow, Python Software Foundation; Chair, PSF UX working group; founder, Jupyter Accessibility working group; Jupyter Distinguished Contributor; emeritus member, PyLadies Global Council; emeritus trustee, UK RSE Association and UK Python Association.
\end{itemize}
\end{cvparagraph}
